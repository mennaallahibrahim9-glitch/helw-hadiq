حلو وحادق - Front-End Website
1) فك ضغط الملف.
2) افتح index.html في المتصفح.
3) صوركم موجودة داخل مجلد images بأسماء founders-1.jpeg إلى founders-4.jpeg.
4) عدّل الأصناف والأسعار من index.html.
5) رابط إنستجرام الحالي يفتح Instagram فقط؛ استبدله برابط حسابكم الحقيقي عند إرساله.
ملاحظات:
- الأسعار الحالية تجريبية وليست أسعارًا مؤكدة.
- الصور والخطوط وأيقونات Font Awesome يتم تحميل بعضها من الإنترنت.
- زر إضافة الطلب تجريبي فقط، ولا يوجد نظام دفع أو Backend.

تحديث الألوان: تركواز/بترولي مع أصفر مانجو وبرتقالي وكريمي.
